# Launch plan

Use one accurate message everywhere: StudyAgent is an evaluation-first open-source RAG study assistant for private documents. Link the repository and release, disclose the Spanish-only UI and missing public evaluation baseline, and use this CTA: “Try it, tell me what breaks, and open an issue if you find something useful to improve.”

- **GitHub profile:** pin the repository and summarize the working features and explicit limitations.
- **Show HN:** lead with the technical problem, architecture, reproducible setup, and what was learned. Be available to answer implementation questions.
- **Reddit and RAG/LLM/MCP communities:** post only where project showcases are permitted; tailor the technical angle and avoid cross-post spam.
- **LinkedIn:** focus on the release, engineering decisions, and invitation for concrete feedback rather than vanity metrics.
- **University communities:** present it as a self-hostable study workflow and request usability/accessibility feedback without collecting private coursework.
- **Technical writing:** publish deep dives on retrieval evaluation, RLS boundaries, or MCP reuse with reproducible evidence and links to source.

Track only authentic stars, forks, releases, users, issues, and external contributions. Respond promptly, label issues consistently, and convert repeated questions into documentation.
